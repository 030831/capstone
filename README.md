# 늘봄 — 세 가지 학습 지원 프로토타입

특수학급 학생의 다양한 지원 필요를 고려해, ‘문제 + AI’에서 한 걸음 더 나아갈 경험을 비교하는 React 시제품입니다. 국내 특수교육 자료와 서비스·오픈소스·학습 연구를 조사한 뒤 제작했습니다.

## 실행

Node.js 22.12 이상(또는 호환되는 최신 버전)이 필요합니다.

```sh
npm install
npm run dev -- --port 4173
```

[처음 화면](http://127.0.0.1:4173/)

| 체험 | 주소 | 핵심 흐름 |
|---|---|---|
| A 한 걸음 교실 | [시작하기](http://127.0.0.1:4173/#/focus) | 목표·활동량 선택 → 한 행동씩 → 쉬기 → 맥락 복구 → 기록 |
| B 도움 사다리 | [시작하기](http://127.0.0.1:4173/#/bridge) | 같은 목표·다른 도움 → 새 문제 확인 → 지원과 첫 시도 구분 |
| C 생활 실험실 | [시작하기](http://127.0.0.1:4173/#/life) | 준비물 읽기 → 수량 담기 → 합계·예산·거스름돈 → 바뀐 상황 |
| 보호자 기록 | [기록 보기](http://127.0.0.1:4173/#/records) | 실제 체험 결과, 첫 시도·힌트·읽기 지원, 기록 내려받기 |

세 체험은 서로 다른 지원 가설을 보여줍니다. 첫 화면에서 자유롭게 오갈 수 있고, 진행 중인 학습은 같은 브라우저에서 이어갈 수 있습니다.

## 현재 되는 것과 경계

- 직접 작성한 문제와 단계별 도움말, 채점·재시도·중단/재개·결과 기록이 동작합니다.
- 읽어주기는 브라우저의 한국어 음성 지원에 따라 달라집니다. 음성이나 그림만으로 정보를 전달하지 않습니다.
- 실제 AI API는 연결하지 않았습니다. 비밀키는 코드에 넣지 않았고 준비된 문제 체험임을 표시합니다.
- 학습 기록은 이 브라우저에만 저장됩니다. 실제 로그인·부모 인증·다른 기기 동기화는 구현하지 않았습니다.
- 학습효과·특수교육 대상 적합성·임상적 효과는 검증하지 않았습니다. 진단명으로 문제 수준을 자동 결정하지 않습니다.

## GitHub Pages에 올리기

배포 워크플로를 `.github/workflows/deploy.yml`에 준비했습니다. 새 GitHub 저장소에 소스를 올리고 기본 브랜치를 `main`으로 사용한 뒤, 저장소 **Settings → Pages → Source → GitHub Actions**를 선택하면 됩니다. 다른 기본 브랜치를 쓰면 워크플로의 `branches`를 바꾸세요.

`base: './'`와 해시 경로를 사용하므로 저장소 이름을 코드에 적지 않아도 됩니다. 배포하는 산출물은 `dist` 폴더입니다. 현재 실제 저장소 업로드와 원격 배포는 하지 않았습니다.

사용자가 제공한 원문 PDF·PPT와 조사 과정에서 추출한 원문 전체는 공개 저장소에 올리기 전에 각 자료의 이용 조건을 확인하세요. 사이트 실행에 원문 파일은 필요하지 않습니다.

## 검증

```sh
npm test
npm run build
```

브라우저 시나리오 테스트:

```sh
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" npx playwright install chromium
mkdir -p .cache/tmp
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" TMPDIR="$PWD/.cache/tmp" npm run test:e2e
```

실행한 검증의 상세 결과는 `QA.md`에 기록합니다. 테스트는 소프트웨어 동작 검증이며 실제 학생의 학습효과 실험이 아닙니다.
