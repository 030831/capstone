# Prototype implementation contract

Each module exports default function Component({onRecord, onHome, settings}). Implement only your assigned .jsx and .css in this folder. Import own css; scope all CSS under .focus-proto / .bridge-proto / .life-proto. Root handles global header, route and parent report. Shared utilities: import {usePersistentState, speak, makeId} from '../lib/storage'; React, lucide-react installed by root. Settings: {largeText:boolean, quiet:boolean}. Parent uses root type selector; your component may have own completion summary.

onRecord({id: stable session id, prototype:'focus'|'bridge'|'life', subject:'국어'|'수학'|'생활', title:string, completedAt:new Date().toISOString(), questions:[{id,prompt,firstCorrect:boolean|null,correct:boolean,attempts:number,hints:number,accessSupports:string[]}], resumed:number, reflection:string, mode:'prepared-demo'}) when session finished, once only (root dedupes). Preserve firstCorrect on retries. TTS/readability supports don't count as hints. Null means no first response; do not count skipped as wrong. No real API key or network AI needed: prepared demo disclosed by shell. No diagnosis, fabricated mastery%, fake student records. Session progress uses usePersistentState with unique key 'focus-progress' etc. onHome navigates comparison hub. App must handle empty/failure/pause, reset own progress. Do not overwrite root files.

Shared global CSS styles: .btn (base), .btn-primary (green default), .btn-secondary (white border), .btn-ghost, .eyebrow, .muted. May use or override within wrapper. Buttons keyboard accessible, focus states, label inputs, aria-live polite for feedback, avoid automatic advance. 360px mobile and tablet/desktop responsive. Use CSS and own SVG for artwork; no copied assets, no external fonts requirement.
