# 곱셈 활동지 (늘봄 디자인)

특수학급 초·중학생용 곱셈 활동지 시안이다. 기본 교육과정 중학교 1~3학년 수학의 성취기준 [9수학01-08]~[9수학01-10]을 묶어 세기 → 곱셈식 → 곱셈구구 → 생활 속 곱셈 순서로 다룬다. 화면에서 풀 수 있고, 그대로 A4에 인쇄해 종이 활동지로 쓴다.

- 이 폴더는 `main`의 늘봄 앱과 따로 있는 정적 페이지다. 늘봄 앱의 빌드와 테스트에 영향을 주지 않는다.
- 색, 글꼴, 머리말은 늘봄 사이트의 값을 가져왔다.
- 가상 사례다. 학생의 이름이나 점수를 저장하지 않는다. 풀이 기록은 화면을 닫으면 사라진다.

## 바로 보기

사이트: https://030831.github.io/capstone/multiplication-worksheet/

배포는 `public/multiplication-worksheet/index.html`(이 폴더의 `index.html`과 같은 파일)을 Vite가 그대로 복사해서 된다. 활동지를 다시 빌드하면 두 파일을 함께 바꾼다.

`index.html`을 브라우저로 연다. 다른 파일 없이 열린다(그림이 파일 안에 들어 있다).

## 구성

| 묶음 | 장면 | 내용 | 쪽 |
|---|---|---|---|
| 가 | 과일 가게 | 귤 봉지를 묶어 세기 | 3 |
| 나 | 문구점 | 연필 다발의 수를 덧셈식에서 곱셈식으로 | 3 |
| 다 | 빵집 | 도넛 상자로 곱셈구구(1~9단, 교사가 단을 고름) | 3 |
| 라 | 편의점 | 묶음과 줄에서 곱셈식 만들기, 쓰지 않는 수 가려내기 | 3 |
| 마 | 여러 곳 | 섞어 풀기 | 2 |

- 묶음마다 문제는 7개(마는 6개)이고, 연달은 두 문제 사이에 한 가지만 바뀐다.
- 1쪽은 생각 열기와 1~3번, 2쪽은 4번·알아보기·5번, 3쪽은 6~7번·정리·돌아보기다.
- 화면은 세 층이다. **단계 목록**(가~마, 단계마다 무엇을 배우는지 한 줄) → **단계**(생각 열기, 문제 목록: 문제마다 역할(시작·이어서·막히는 곳·새 방법·혼자 해 보기)과 "이 문제에서 하는 일" 한 줄, 풀었는지) → **한 문제씩 풀기**(위쪽 순서 띠, 이전·다음). 알아보기와 정리는 순서 안의 한 칸이다.
- 인쇄용 활동지는 단계 화면의 "인쇄용 활동지"에서 따로 연다(묶음마다 A4 3쪽, 마는 2쪽).
- 화면에서는 보기를 고르고 "확인"을 누른다. 그림의 묶음을 누르면 그 묶음까지의 수가 붙는다.
- 알아보기는 4번을 푼 뒤, 정리는 모두 푼 뒤 열린다. 인쇄에서는 모두 보인다.
- "다른 수로 한 번 더"를 켜면 같은 구조의 문제가 다른 수로 나온다(가, 나, 라).

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 활동지 (빌드 결과) |
| `worksheets/ws5.src.html` | 화면 원본 (HTML, CSS, JS) |
| `worksheets/build5.py` | 빌드: 문제 데이터와 그림을 넣어 `ws5.html`, `ws5_local.html`을 만든다 |
| `worksheets/check5.py` | 검사: 모든 묶음 × 단 × 한 번 더를 돌며 쪽 높이, 정답, 보기, 풀이를 확인한다 → `check5_result.json` |
| `worksheets/shot5.py`, `print5.py` | 화면 캡처, PDF 인쇄와 쪽 그림 |
| `worksheets/v4/mult_items.json` | 문제 데이터 (수, 순서, 보기, 도움말) |
| `worksheets/art/v5/selected/` | 삽화와 `manifest.json` (그림마다 고른 후보와 눈으로 센 개수) |
| `worksheets/art/v5/log.csv`, `gen_art_v5.py`, `select2.py` | 삽화를 만든 기록(프롬프트, 시드)과 스크립트 |
| `worksheets/art/sets/fluent_flat/` | 대체용 그림 (지금 화면에서는 쓰이지 않음) |
| `refs/design/lucide/` | 아이콘 |
| `docs/` | 설계 문서 |

다시 빌드하려면 Python 3과 Pillow가 필요하다.

```
python -X utf8 worksheets/build5.py
python -X utf8 worksheets/check5.py     # Chrome이 필요하다
```

## 한계

- 교사나 학생이 써 본 적이 없다. 문제의 수, 도움말, 쪽 구성은 초안이다.
- 삽화는 생성 모델로 만든 것이다. 전문 삽화가의 작업과 같다고 말할 근거는 없다.
- 화면 캡처와 인쇄 결과를 직접 본 것은 일부 쪽이다(가·나 전체, 다·라·마의 일부).
- 휴대폰처럼 좁은 화면에서는 활동지가 같은 비율로 줄어들어 글자가 작아진다. 태블릿과 노트북, 인쇄를 기준으로 만들었다.
- 한 묶음이 3쪽이다. 글자 20px과 그림 크기를 지키면 2쪽에 들어가지 않는다.
