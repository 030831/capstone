- 작성: 2026-11-23, Claude

- 근거 조사: `14_그림_제작_방법_조사.md`(방법 15개 비교), 표본과 렌더: `claude/refs/art/samples/`

## 1. 지금까지의 방법과 문제 (3판 화면을 직접 보고 확인)

| 본 것 | 원인 |
|---|---|
| 물건이 반쯤 빈 단추 상자 안에 24~36px로 놓여 양식처럼 보임 | 물건 하나짜리 작은 아이콘을 칸에 넣는 구조 |
| 봉지·묶음·줄이 글자 단추, 용기 그림이 없음 | 묶음을 나타내는 그림을 만들지 않음 |
| 연필이 가는 대각선, 도넛이 3+1 비대칭 | 생성 그림의 형태를 눈으로 고르지 못함 |
| ARASAAC 상징, UI 단추, Qwen 장면의 화풍이 섞임 | 세트 단위의 화풍 기준이 없음 |

## 2. 정한 방법: 전문가가 만든 한 세트 + 용기는 같은 화풍으로 코드 합성

조사 문서의 방법 M1(이모지 그림 한 세트로 고정) + M2(용기와 물건을 코드로 합성)다.

| 근거 | 출처 |
|---|---|
| 이모지 4세트(Fluent, Noto, Twemoji, OpenMoji)는 필요한 낱개 물건을 모두 갖고 있고 한 세트가 한 화풍이다 | `14_` 4절, 파일 목록으로 확인 |
| 생성 모델은 물건의 개수를 정확히 그리지 못한다(GenEval counting 0.74~0.89, 2~4개만 시험). 개수를 구조로 보장하는 방법은 코드 합성뿐이다 | `14_` 3절 M2, 5절 |
| "용기 + 안의 물건 n개" 그림은 공개 세트에 없다(확인한 범위) | `14_` 4절 |
| 세는 물건은 꾸밈이 많을수록 오류가 늘었다(McNeil 외 2009, "perceptually rich" 조건에서 오류 최다) → 평면이고 단순한 그림 | `14_` 2절 |
| "그림, 사진 등의 시각자료 가운데 하나의 양식을 활용", "전체적인 삽화의 일관성 유지" | 국립장애인도서관 지침, `14_` 2절 |
| 지금 바로(GPU·비용·계정 없이) 할 수 있다 | `14_` 3절 |

주 세션이 렌더 시트(`refs/art/samples/_render/sheetA.png`, `sheetB.png`, `compare_sheet.png`)를 직접 보고 확인한 것: Fluent Flat, Noto, Twemoji는 256px과 36px 모두에서 귤·연필·도넛·달걀·의자가 또렷하게 알아보인다. OpenMoji와 Mulberry는 굵은 외곽선 화풍이고 Mulberry의 연필은 가늘다.

## 3. 용기와 묶음 (코드로 그리는 SVG, 세트와 같은 평면 화풍)

외곽선을 쓰지 않고, 색은 그 세트의 그림에서 뽑은 색만 쓴다. 물건은 모두 온전히 보여야 한다(셀 수 있어야 하므로 겹치거나 가리지 않는다).

| 묶음 | 용기 그림 | 안의 배치 |
|---|---|---|
| 귤 봉지 | 투명한 비닐봉지: 아래가 둥근 주머니 모양(옅은 하늘색, 반투명), 위는 모아 묶은 매듭 | 2개: 나란히 / 3개: 삼각 / 4개: 2×2 / 5개: 위 2 + 아래 3 |
| 연필 묶음 | 똑바로 선 연필 n자루가 나란히 붙어 있고, 가운데를 띠(고무줄) 하나가 가로지른다 | 한 줄 |
| 도넛 상자 | 위에서 본 열린 상자: 상자 색 둥근 사각형 + 안쪽 밝은 바닥 | 2개: 1×2 / 3개: 1×3 / 4개: 2×2 / 5개: 주사위 5 / 6개: 2×3 / 7개: 3+1+3 / 8개: 2×4 / 9개: 3×3 / 1개: 가운데 |
| 음료수 묶음 | 받침 판(둥근 사각형) 위에 팩이 나란히, 위쪽에 손잡이 띠 | 한 줄 또는 2줄 |
| 줄(배열) | 줄마다 얇은 선반 선 하나 | 줄마다 같은 간격으로 |
| 달걀판 | 판(둥근 사각형) + 칸마다 옅은 원 | 2×3 |
| 학생 줄 | 줄마다 바닥 선 | 같은 간격 |
| 의자 줄 | 줄마다 바닥 선 | 같은 간격 |
| 달력 | 요일 머리 7칸 + 주마다 7칸 줄 | 날짜 없음 |

크기:

- 물건의 짧은 변은 화면에서 40px 이상(활동지 너비 760px 기준). 물건이 30개인 문항만 32px까지 줄일 수 있다.
- 용기 사이 간격은 용기 안의 물건 간격보다 눈에 띄게 넓다(묶음이 묶음으로 보이게).
- 그림 영역은 내용의 크기에 맞춘다. 빈 영역을 남기지 않는다.
- 번호표(눌러 셀 때)는 물건 위 오른쪽 위에 겹쳐 붙인다. 번호표 자리를 따로 비워 두지 않는다.

## 4. 장면 그림 (생각 열기)

- 기존 Qwen 장면 그림은 가는 외곽선이 있는 다른 화풍이다. 4판 화면에서 세트 그림과 나란히 놓고 직접 본 뒤 정한다.
- 대안: 세트의 그림만으로 만든 띠(가게 그림 + 물건 몇 개를 선반에 놓은 그림). 화풍이 한 가지로 맞는다.

## 5. 확인 방법

1. 주 세션이 묶음별 스크린숏을 직접 열어 본다: 용기가 용기로 보이는가, 묶음이 묶음으로 보이는가, 물건이 모두 온전히 보이는가, 빈 영역이 없는가, 화풍이 한 가지인가.
2. 수치: 물건의 짧은 변, 물건 수 = 한 묶음의 수 × 묶음 수, 한 쪽의 높이, 색이 세트의 색 안에 있는가.
3. 사용자가 아티팩트에서 직접 본다. 세트(Fluent Flat / Noto)는 교사용 영역에서 바꿔 볼 수 있다.

## 5-2. 실제 공식 자료를 직접 보고 고친 기준 (2026-11-23)

사용자가 "자료 찾아 놓은 것 있을 텐데"라고 해서 확인하니, 이 단원의 공식 자료가 이미 `claude/refs/kr/mid_math/`에 있었다(교과서, 학습 활동지 3종, 평가지 6종, 지도서). 그동안 글자로만 읽었고, 이번에 쪽을 그림으로 뽑아(`pages/`) 직접 봤다.

| 자료 | 직접 본 것 |
|---|---|
| 공식 학습 활동지 1쪽 | 머리에 "학습 활동지 1 / 수학 5단원", 제재명·학습 주제·이름·교과서 쪽. 얇은 테두리의 큰 그림 칸에 **같은 사과 그림 한 장을 4×3으로 12번 반복**. 물건 하나가 쪽 너비의 약 8%. "컵 하나에 빨대 2개" 그림을 2번, 5번 반복하고 오른쪽에 "2개씩 □묶음". 첫 답은 예시로 채워져 있다. 한 쪽에 활동 2개, 꾸밈은 거의 없다 |
| 교과서 138~139쪽 | 분홍 머리띠와 차시 제목, "생각 열기" 상자, 교실 장면 삽화(학생 2명) 위에 실물 사진(봉지에 든 테이프 2개씩, 학용품 묶음). 빈칸은 하늘색 테두리 네모 + 단위 글자 |
| 교과서 150~151쪽 (2단) | "2 × 2 = □" 식 칸 아래에 나무 집게 묶음 사진. 떡이 2×6으로 놓인 사진과 "2 × □ = □ → □개". 놀이기구 장면 삽화 |

이로써 바뀌는 기준:

- 물건의 짧은 변은 활동지 너비의 7~9%(760px에서 52~68px). 2절의 40px 기준을 이것으로 바꾼다. 30개짜리 문항만 40px까지.
- "용기 + 물건 n개"를 한 그림 단위로 만들어 묶음 수만큼 반복한다(공식 활동지의 컵 + 빨대 방식). 공식 자료도 같은 그림 한 장을 반복해 놓는다.
- 머리에 제재명, 학습 주제, 이름, 교과서 쪽을 넣는다.
- 첫 답을 예시로 보여 주는 선택지를 둔다(교사가 끔/켬).
- 공식 활동지의 그림은 윤곽선과 광택이 있는 벡터 그림이다. Fluent Flat(평면)과 Noto(밝은 면이 있음) 가운데 어느 쪽이 가까운지는 같은 화면으로 찍어 놓고 보고 정한다.
- 교과서 본문은 삽화 장면과 실물 사진을 함께 쓴다. 실물 사진을 쓰는 방식(`14_` M7)은 지금 세트로 만든 뒤 비교할 다음 후보다.

저작권이 있는 자료라서 그림과 지면은 복제하지 않는다.

### 공식 자료는 최저선이다 (사용자, 2026-11-23)

"따라 만들라는 게 아니라 퀄리티 수준을 최소한 실제 자료보다 높게 만들라는 거야." 위 표의 내용을 닮게 만드는 것이 목표가 아니다. 아래 항목 하나하나에서 공식 자료보다 낮지 않아야 한다. 판정은 공식 자료의 쪽 그림과 우리 화면을 나란히 놓고 직접 보고, 잴 수 있는 것은 잰다.

| 항목 | 공식 자료에서 본 것 | 넘는 방법 | 확인 |
|---|---|---|---|
| 그림 해상도 | 활동지의 사과는 213 × 210px JPEG 한 장을 반복 | 벡터 그림 | 잼(원본 형식, 해상도 비율) |
| 화풍의 일관성 | 광택 사과와 가는 선의 컵, 교과서는 삽화와 실물 사진이 섞임 | 한 세트의 한 화풍, 용기도 그 세트의 색으로 | 봄 |
| 묶음의 표현 | 컵 + 빨대는 분명하지만 사과는 격자로만 놓임 | 모든 문항에서 묶음이 그림만으로 분명 | 봄 |
| 그림의 정렬 | 그림 칸 안에서 한쪽으로 쏠린 곳이 있음 | 가운데 정렬, 고른 간격, 대칭 배치 | 봄, 잼(좌우 여백 차이) |
| 글자와 대비 | 지시문 약 13pt, 옅은 하늘색 빈칸 테두리 | 지시문 인쇄 13.6pt 이상, 글자 대비 4.5 이상, 빈칸 테두리 대비 3 이상 | 잼 |
| 지면 구성 | 활동이 낱개로 놓임 | 문항 번호, 구분선, 알아보기·정리 상자로 흐름이 보임 | 봄 |
| 문항 사이의 관계 | 드러나지 않음 | 앞 문항과 한 가지만 다른 순서(`5_곱셈_단계학습.md`) | 잼(이미 검사 있음) |
| 종이에 없는 것 | — | 눌러 세기, 읽어 주기, 확인과 다시 하기, 교사용 기록, 인쇄 | 풀이 검사 |

"더 높다"고 말할 수 있는 것은 잰 항목과 직접 본 항목까지다. 삽화의 예술적 완성도처럼 보는 사람에 따라 갈리는 부분은 사용자가 아티팩트에서 보고 판단한다.

## 6. 한계

- 용기 그림은 전문가가 그린 것이 아니라 코드로 그린 것이다. 세트의 화풍에 맞췄는지는 눈으로 확인한다.
- 이모지 세트의 그림은 교과서 삽화용으로 만든 것이 아니다. 교육부·국립특수교육원의 삽화 기준 원문은 찾지 못했다(`14_` 7절).
- 캔 그림이 세트에 없어 음료수는 팩으로 그린다.
- GPU를 쓸 수 있게 되면 화풍을 맞춘 생성 그림(`14_` M9~M11)을 같은 세트 구조에 추가해 비교할 수 있다.
