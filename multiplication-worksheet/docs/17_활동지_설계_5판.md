# 곱셈 활동지 설계 (5판) — 유료 교재 수준의 지면과 삽화

- 작성: 2026-11-24, Claude
- 사용자의 4판 평가(2026-11-24): "일반적인 흰색 배경에 이모티콘이나 이미지 몇 개 넣고 문제 넣고 끝인 느낌이라 실제로 교사나 학부모들이 비용을 지불하고 받는 퀄리티는 아닌 것 같아."
- 바뀌지 않는 것: 문제의 수와 순서(`5_곱셈_단계학습.md`), 교과서 문체, 늘봄 사이트의 색·글꼴·단추(`13_늘봄_활동지_설계.md` 3절), 접근성 수치(글자 20px 이상, 대비 4.5 이상, 누르는 대상 44px 이상), 진척 지표와 자동 진행 금지.
- 바뀌는 것: 지면의 구성과 그림. 이 문서가 4판의 4~8절을 대신한다.

## 1. 근거: 돈을 내고 사는 교재의 실물 (주 세션이 직접 본 것)

표본 32개(`16_유료_학습지_표본.md`, 그림 `refs/paid/`, 대조 시트 `_sheet_1~3.png`)와 이 단원의 교과서·공식 활동지(`refs/kr/mid_math/pages/`)를 직접 열어 봤다.

| 표본에서 본 것 | 표본 수 (32개 중) | 예 |
|---|---|---|
| 쪽머리에 일차·단계 번호 배지와 색 띠 | 15 | 소마셈 "1일차 묶어 세기", 원리셈, 개념이 답이다 |
| 반복해서 나오는 캐릭터 | 16 | 소마셈 부엉이, 교실을 위한 곱셈구구의 원숭이 |
| 문제마다 옅은 색 카드에 담겨 격자로 놓임 | (국내 교재 대부분) | 소마셈, 원리셈: 한 쪽에 문제 4~8개 |
| 세는 물건이 문제마다 줄·상자·접시에 놓임 | 20/25 | 원리셈: 접시 위의 귤, 소마셈: 상자 안의 꽃 |
| 세는 물건이 장면 안에 통합됨 | 3/25 | 기적의 유아수학: 냉장고 |
| 쪽 전체가 색·그림으로 채워짐 | 12 | 신비아파트, 기적의 유아수학 |
| 흰 바탕에 그림과 문제만 | 9 | 해외 워크시트 8개, IXL |

국내 유료 교재 11개 가운데 9개가 캐릭터·장면·전면 색 중 하나 이상을 쓰고, 나머지 2개도 색 상자와 띠가 있다. **4판은 "흰 바탕에 그림과 문제만"에 해당한다.**

유료 교재를 유료로 보이게 하는 것은 문제마다 장면을 넣는 일이 아니다(3/25). 다음 네 가지다.

1. 쪽마다 반복되는 **지면의 틀**: 색 띠, 단계 배지, 쪽 번호 표시.
2. 문제를 담는 **옅은 색 카드의 격자**와 그 안의 고른 정렬.
3. 한 화풍의 **삽화**와 반복해서 나오는 **캐릭터**.
4. 한 쪽에 문제 4~8개인 **밀도**.

교과서(국립특수교육원)는 여기에 더해 차시의 처음에 큰 장면 삽화("생각 열기")를 둔다.

## 2. 지면의 틀

한 묶음 = 2쪽(가·나·다·라), 마는 2쪽. 한 쪽은 A4 한 장.

| 요소 | 내용 | 가져온 곳 |
|---|---|---|
| 쪽머리 띠 | 쪽 너비 전체의 옅은 색 띠(묶음의 색). 왼쪽에 단계 배지(둥근 사각형 안에 "가", 그 아래 작은 글 "1 / 2"), 가운데에 차시 제목, 오른쪽에 캐릭터의 머리(띠 위로 조금 올라옴) | 표본: 일차 배지와 색 띠(15/32). 색은 늘봄의 강조색 묶음 |
| 이름 줄 | 1쪽에만: 제재(번호만), 학습 주제, 이름, 날짜. 2쪽은 이름만 | 공식 활동지의 머리 |
| 생각 열기 | 1쪽에만: 쪽 너비 전체의 장면 삽화(높이 약 210px) 위에 캐릭터의 말풍선 한 문장 | 교과서 "생각 열기", 표본: 장면 삽화(11/32), 말풍선(5/32) |
| 문항 카드 격자 | 옅은 색(묶음의 tint) 둥근 카드. **2열 격자**가 기본, 그림이 넓은 문항(묶음 5개 이상, 긴 덧셈식)은 2열을 합친 넓은 카드 | 표본: 소마셈, 원리셈의 카드 격자 |
| 알아보기 | 넓은 카드. 왼쪽에 캐릭터, 오른쪽에 말풍선 모양의 설명과 그림 | 표본: 개념 상자 + 캐릭터 |
| 정리 | 2쪽 끝의 넓은 카드. 캐릭터 + 방법의 이름 한 문장 | 교과서의 정리 문장 |
| 쪽 아래 | 왼쪽에 묶음 색의 작은 배지와 "곱셈 · 가 · 1/2", 오른쪽에 출처 표시 | 표본: 쪽 아래의 책 이름·단계 |

### 묶음의 색 (늘봄 `styles.css`의 강조색 묶음)

| 묶음 | 늘봄 클래스 | accent | tint | deep |
|---|---|---|---|---|
| 가 과일 가게 | `.peach` | #8a573e | #f7ebdf | #8a563c |
| 나 문구점 | `.lavender` | #73638c | #eeeaf4 | #55466f |
| 다 빵집 | gold (늘봄 `.mini-axes`의 색) | #7e604a | #fff8ec | #7a5c47 (테두리 #e5d3bb) |
| 라 편의점 | `.sage` | #436f58 | #e7efe2 | #345d49 |
| 마 섞어 풀기 | 늘봄 기본 초록 | #315d4f | #f1f4eb | #33473d |

- 카드의 바탕은 tint, 배지와 제목 강조는 deep, 선택 표시는 accent. 글자색은 늘봄의 활동지 글자 `#22322b` 그대로.
- tint 위의 글자 대비는 구현할 때 계산해 4.5 이상인지 확인한다.

### 문항 카드 (한 장)

위에서 아래로: 번호 배지(카드 왼쪽 위, 묶음 색 원) + 문제 글(2줄 이하) → 그림(카드 안 가운데, 흰 바탕의 둥근 칸 없이 tint 위에 바로. 그림 아래에 옅은 바닥 그림자) → 답 줄("모두 □ 개" 또는 식) → 보기 4개(한 줄, 카드 너비를 4등분). 모든 카드에서 순서와 자리가 같다.

- 2열 카드의 안쪽 너비는 약 330px. 봉지 2~4개가 한 줄 또는 두 줄로 들어간다.
- "확인" 단추는 보기 줄 아래 오른쪽(화면에서만, 보기를 고르면 나타남). 결과는 같은 줄 왼쪽.
- 인쇄에서는 보기의 둥근 표시에 연필로 표시한다.

### 쪽 나누기

| 묶음 | 1쪽 | 2쪽 |
|---|---|---|
| 가 | 띠, 이름 줄, 생각 열기, 문항 1·2·3(3번은 넓은 카드 또는 2열), 4(넓은 카드) | 띠, 알아보기, 문항 5(넓은 카드), 6(넓은 카드), 7, 정리 |
| 나 | 띠, 이름 줄, 생각 열기, 문항 1·2·3, 4(넓은 카드: 긴 덧셈식) | 띠, 알아보기, 문항 5(넓은 카드), 6, 7, 정리 |
| 다 | 띠, 이름 줄, 생각 열기, 곱셈표, 문항 1·2·3, 4(넓은 카드) | 띠, 알아보기, 문항 5(넓은 카드), 6(넓은 카드), 7, 정리(곱셈표 전체) |
| 라 | 띠, 이름 줄, 생각 열기, 문항 1·2·3, 4(넓은 카드) | 띠, 알아보기, 문항 5·6(넓은 카드), 7(넓은 카드), 정리 |
| 마 | 띠, 이름 줄, 문항 1·2·3·4 | 띠, 문항 5·6, 정리 |

- 예시 문항은 교사 선택(기본 끔). 켜면 1쪽 생각 열기 아래에 넓은 카드로 들어가고, 넘치는 문항은 쪽을 하나 더 만든다(그때만 3쪽).
- 한 쪽의 높이가 넘치면 그림의 크기를 정해진 단계(100% → 88% → 76%)로 줄인다. 글자 크기는 줄이지 않는다.

## 3. 삽화

| 종류 | 만드는 법 | 쓰는 곳 |
|---|---|---|
| 묶음 단위 그림 (봉지에 든 귤 n개, 띠로 묶은 연필 n자루 등) | Qwen-Image 2.1로 생성. 한 묶음의 기준 그림 하나를 정하고 참조 편집으로 수만 바꾼다. 주 세션이 직접 보고 개수와 모양을 확인한다 | 문항의 그림. 같은 단위 그림을 묶음 수만큼 반복해 놓는다 |
| 낱개 그림과 빈 용기 (도넛, 음료수, 달걀, 상자, 판) | 생성. 개수가 5를 넘는 단위는 빈 용기 그림 위에 낱개 그림을 코드로 놓는다 | 다 묶음(도넛 상자 1~9개), 달걀판, 줄 |
| 장면 삽화 (가게) | 생성, 1344×576 | 생각 열기 |
| 캐릭터 (늘봄 새싹) | 생성. 기준 자세 하나에서 참조 편집으로 자세를 바꾼다 | 쪽머리 띠, 생각 열기의 말풍선, 알아보기, 정리 |
| 달력, 곱셈표, 식, 빈칸, 선반 선 | 코드 | — |

- 화풍 기준: `worksheets/art/gen/scene_fruit_1_1.png`와 1차 시안(`worksheets/art/v5/`). 가는 갈색 외곽선, 따뜻한 색, 부드러운 명암.
- 개수는 생성에 맡기지 않는다. 단위 그림마다 주 세션이 눈으로 센 값을 기록하고, 틀린 그림은 쓰지 않는다. 5개를 넘으면 코드로 놓는다.
- 사람 그림은 만화풍의 성인(가게 주인)만. 학생·어린이 그림은 만들지 않는다. 라 7번은 "학생 5명씩 6줄" 대신 "삼각김밥 5개씩 6줄"로 한다(앞 문제와 물건만 바뀌는 구성은 같다).
- 그림은 화면에 놓이는 크기의 2배 이상 해상도로 넣고, WebP로 압축한다.

필요한 그림의 목록은 1차 시안을 본 뒤 이 절 아래에 적는다.

## 3-2. 구현하면서 바뀐 것 (2026-11-24, 주 세션이 직접 구현)

사용자가 "화면 구성 너가 해줘"라고 해서 5판 화면은 주 세션이 직접 만들었다. 파일은 `worksheets/ws5.src.html`(화면), `build5.py`(빌드), `shot5.py`(캡처와 쪽 높이 측정), `print5.py`(PDF 인쇄와 쪽 그림), 결과는 `ws5.html`(아티팩트용), `ws5_local.html`.

| 설계 | 구현 | 이유 |
|---|---|---|
| 한 묶음 2쪽 | **3쪽** (마는 2쪽) | 글자 20px과 그림 크기를 지키면 2쪽에 들어가지 않는다. 쪽을 역할로 나눴다: 1쪽 생각 열기와 1~3번(도입·전개), 2쪽 4번·알아보기·5번(약한 두통·꼬기), 3쪽 6~7번·정리·돌아보기(마무리) |
| 문항 카드 2열 격자 | 1·2번만 2열, 나머지는 넓은 카드 | 묶음이 4개 이상이면 2열 카드에서 그림이 작아진다. 라 묶음의 줄(배열) 문항은 2열 |
| 그림은 카드의 tint 위에 바로 | 계산대 띠(탁자 그림의 윗면을 잘라 낸 것) 위에 묶음 그림을 세움 | 합성 시험에서 탁자 위에 놓인 모습이 가장 자연스러웠다 |
| 예시 문항(교사 선택) | 넣지 않음 | 구성을 단순하게 유지 |
| 그림 세트 바꾸기 | 넣지 않음. 생성 삽화가 없는 물건만 Fluent 그림으로 대체 | 같음 |
| — | 돌아보기 줄("혼자서 했습니다 / 도움을 받아 했습니다", 확인 칸) | 교과서의 "학습 돌아보기", 늘봄의 조건 축(독립 수행 / 도움 받아 수행) |
| — | 화면에서는 알아보기가 4번을 푼 뒤, 정리가 모두 푼 뒤 열린다. 인쇄에서는 모두 보인다 | 좋은 문제의 조건 4 |

한 쪽은 760 × 1075px로 고정하고, 좁은 화면에서는 같은 비율로 줄인다. 인쇄할 때는 한 쪽이 A4 한 장을 여백 없이 채운다(색 띠가 종이 끝까지 닿는다).

## 4. 확인

1. 주 세션이 묶음별 2쪽을 화면 캡처와 인쇄 결과(PDF를 그림으로 뽑은 것)로 직접 본다. 유료 교재 대조 시트(`refs/paid/_sheet_1.png`)와 나란히 놓고 1절의 네 가지(지면의 틀, 카드 격자, 삽화와 캐릭터, 밀도)가 있는지 확인한다.
2. 수치 검사: 4판의 기준 1~12 + 묶음당 2쪽(예시 켬이면 3쪽 이하) + 한 쪽의 문항 3개 이상(마지막 쪽 제외) + 카드 안 요소의 순서가 모든 문항에서 같음 + tint 위 글자 대비 4.5 이상.
3. 사용자가 아티팩트에서 본다.

## 5. 한계

- 표본의 비율은 모은 32개 안의 사실이고 시장 전체의 비율이 아니다.
- 유료 교재의 표본은 일반 학생용이 대부분이다. 특수교육용 유료 곱셈 교재의 지면은 찾지 못했다.
- 생성 삽화의 완성도는 주 세션이 보고 고르지만, 전문 삽화가의 작업과 같다고 말할 근거는 없다. 사용자가 보고 판단한다.
