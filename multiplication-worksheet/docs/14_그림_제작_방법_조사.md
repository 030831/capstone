## 1. 한 줄 요약 (사실만)

- **교과서 삽화 방식**: 특수교육 기본교육과정 국어과 교과서 6책 1,668쪽 분석에서 "삽화의 종류는 그림이 가장 많았다"(2023, 초록). 수학 교과서의 사진·그림 비율, 교육부 「편찬상의 유의점」 삽화 조항과 국립특수교육원 삽화 지침 원문은 **찾지 못했다**. 발달장애인 읽기 쉬운 책 지침(국립장애인도서관)에는 "그림, 사진 등의 시각자료 가운데 하나의 양식을 활용하는 것이 좋다", "전체적인 삽화의 일관성 유지를 중요시해야 한다"가 있다.
- **세는 물건 그림**: 화려한 구체물이 오히려 오류를 늘린 실험(McNeil 외 2009, 4·6학년 N=229, 5학년 N=79)과, 아는 물건을 세는 취학 전 아동에서 화려한 물건이 방해였다는 보도(2013)가 있다. 수학 교구에는 "rather bland"(밋밋한) 물건이 많다는 서술이 같은 논문에 있다.
- **가져다 쓸 세트**: 낱개 물건(귤·연필·도넛·음료팩/캔·달걀·의자·학생·달력·쇼핑백·상자·컵라면·공·편의점·학교)은 이모지 4세트(Fluent, Noto, Twemoji, OpenMoji)가 모두 가졌고 라이선스(MIT / Apache-2.0 / CC BY 4.0 / CC BY-SA 4.0)가 졸업작품·비영리 공개에 쓸 수 있는 조건이다. **"용기 + 안의 물건 n개"를 한 그림으로 가진 세트는 확인한 범위에 없다.** 달걀판 안에 달걀 3개가 담긴 그림은 ARASAAC(id 27836, CC BY-NC-SA)에서 직접 열어 확인했으나 개수가 3으로 고정이다.
- **생성 모델의 개수**: GenEval counting(2·3·4개만 시험)에서 Qwen-Image 0.89, Z-Image 0.78, FLUX.1 dev 0.74. "controlling the number of depicted objects using text is surprisingly hard"(Make It Count, CVPR 2024). 조사한 7개 외부 서비스·5개 로컬 모델 카드 어디에도 "그림 속 물체를 정확한 개수로 그린다"는 공식 주장은 없었다. 개수를 구조로 정하는 방법은 물건 그림 1개를 코드(SVG `<use>`, Pillow paste)로 n번 배치하는 것뿐이며, 이 방법의 교재 제작 실무 문서는 찾지 못했다.
- **GPU·비용·계정 없이 지금 가능한 방법**: 3절 표의 M1~M8.
